## Proyek Pilihan

### APIHelpDesk — Aplikasi Help Desk

Aplikasi help desk yang terdiri dari frontend web dan backend API. Kedua bagian dikembangkan di repositori terpisah dan digunakan sebagai satu sistem.

- **Frontend:** MyHelpDesk, menggunakan TypeScript, React, dan Vite
- **Backend:** APIHelpDesk, menggunakan ASP.NET Core
- **Komunikasi real-time:** SignalR
- **Basis data:** PostgreSQL dan Microsoft SQL Server
- **Deployment:** konfigurasi Docker Compose dan Nginx
- **Repositori frontend:** [MyHelpDesk](https://github.com/fikriridho177-ai/MyHelpDesk)
- **Repositori backend:** [APIHelpDesk](https://github.com/fikriridho177-ai/APIHelpDesk)

### RSUP DataLogger Collector

Sistem pengumpulan data dan pemantauan operasional untuk menangani data dari beberapa sumber DataLogger. Proyek ini membantu proses pengumpulan, pemeriksaan, dan pelaporan agar kendala pada sumber data dapat ditelusuri.

- Mengelola hasil pengumpulan data dari beberapa vendor
- Mengirim notifikasi dan laporan operasional melalui Telegram
- Menyediakan pemeriksaan status autentikasi dan sensor
- Mencatat audit pengiriman dan menangani kegagalan sumber secara terpisah
- README proyek mencatat 58 tes lulus dan UAT operator selesai

[Repositori RSUP DataLogger Collector](https://github.com/fikriridho177-ai/RSUP-DataLogger-Collector)

### Prototipe Penyortir Ikan Lele Berbasis IoT

Prototipe penyortiran ikan lele otomatis berdasarkan berat. Sistem ini menggabungkan perangkat sensor, mekanisme sortir, dan pemantauan melalui aplikasi.

- Arduino Uno dan ESP32 sebagai bagian dari sistem perangkat
- Load cell dengan HX711 untuk mengukur berat
- Motor servo untuk menggerakkan mekanisme sortir
- Blynk untuk pemantauan
- REST API dan MongoDB untuk penyimpanan data
- README proyek mencatat rata-rata galat sensor sebesar 2,90%

[Repositori Prototipe Penyortir Ikan Lele](https://github.com/fikriridho177-ai/Prototype-Alat-Penyortiran-Ikan-Lele)

### MyPad GHS — Sistem Manajemen Perkebunan

Proyek sistem manajemen perkebunan dengan frontend dan backend yang dikembangkan pada repositori terpisah.

- **Frontend:** TypeScript
- **Backend:** Python
- **Repositori frontend:** [MyPadGHS_FE](https://github.com/fikriridho177-ai/MyPadGHS_FE)
- **Repositori backend:** [MyPadGHS_BE](https://github.com/fikriridho177-ai/MyPadGHS_BE)
- **Repositori MyPad GHS:** [mypad_ghs](https://github.com/fikriridho177-ai/mypad_ghs)

### Logger Arduino

Proyek embedded system berbasis Arduino untuk kebutuhan pencatatan data dari perangkat.

[Repositori Logger Arduino](https://github.com/fikriridho177-ai/logger_arduino)
